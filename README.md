# Projeto Conecta Respeito — Cultura de Paz nas Escolas

> Iniciativa acadêmica de conscientização, prevenção e orientação sobre bullying e cyberbullying.  
> Caráter exclusivamente **informativo e educativo** — sem coleta de dados pessoais.

---

## Descrição

Este projeto é uma landing page acadêmica desenvolvida para apresentar a plataforma **Conecta Respeito**, dedicada à análise, prevenção e combate ao bullying e cyberbullying, promovendo um ecossistema educacional seguro.

---

## Objetivo do Projeto

Desenvolver uma página web responsiva, organizada e documentada, aplicando conceitos iniciais de desenvolvimento front-end, versionamento de código e boas práticas de estruturação de projetos.


---

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
- GitHub Pages
